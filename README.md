AWS CI/CD Pipeline Project 🚀
Project Overview

This project demonstrates a complete AWS CI/CD Pipeline implementation using modern DevOps tools and AWS services.
The pipeline automates the process of building, testing, and deploying a Java web application.

This project was implemented by following concepts learned from the Udemy course:

🎓 Decoding DevOps – AWS CI/CD Pipeline Project

AWS Elastic Beanstalk

AWS RDS (MySQL)

Maven
Java
Tomcat
Jenkins

Architecture Flow 📌
Developer Push Code → Bitbucket Repository → AWS CodePipeline
→ AWS CodeBuild → Artifact Generation → Elastic Beanstalk Deployment
→ Application Hosted on AWS
